UNA FÓRMULA, UN RESULTADO

Calculadora de alcance de proyectil

Calcule el alcance ideal del proyectil cuando las alturas de lanzamiento y aterrizaje coinciden. Elija unidades de entrada y calcule un valor dentro de las condiciones establecidas.

Datos de entrada

Cero o mayor

Ángulo de 0 a 90°

Mayor que cero tras convertir a SI

Puede usar punto o coma decimal. No use separadores de miles. Los cálculos se realizan en este navegador. Se admite notación científica, por ejemplo 1.2e-3. No use separadores de miles.

Resultado

Alcance horizontal entre puntos a la misma altura R

—

Introduzca los valores y pulse Calcular.

FÓRMULA

R = v₀² sin(2θ)/g

Condiciones de aplicación

Requisitos: v₀≥0, g>0, 0≤θ≤90° y alturas de lanzamiento y llegada iguales en gravedad uniforme. Se excluyen la resistencia del aire y la sustentación. Se devuelve un único valor de alcance.

Los valores mostrados son aproximaciones de coma flotante. No se calculan los factores de seguridad de diseño ni las contribuciones de error no introducidas.
